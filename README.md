# Connecting Prototype

A minimal browser-based Phaser 3 prototype built with TypeScript and Vite.

## Project Structure

- `index.html`
- `package.json`
- `tsconfig.json`
- `vite.config.ts`
- `.gitignore`
- `src/
  - `main.ts`
  - `vite-env.d.ts`
  - `scenes/MainScene.ts`
  - `entities/BlobPerson.ts`
  - `systems/ConnectionSystem.ts`
  - `physics/MatterHelpers.ts`

## Packages

Required npm packages:
- `phaser`
- `vite`
- `typescript`
- `@types/node`

## Run Locally

From the project folder:

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.
